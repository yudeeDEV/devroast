# DevRoast 🔥

> **Projeto desenvolvido durante o NLW da Rocketseat** - Um aplicativo web divertido para analisar e criticar (roast) código do usuário de forma honesta e bem-humorada.

[![NLW Rocketseat](https://img.shields.io/badge/NLW-Rocketseat-FF8400?style=flat-square)](https://rocketseat.com.br)

## ✨ Funcionalidades

### 📝 Área de Código
- **Editor de código** interativo com line numbers
- **Análise automática** do código ao submeter
- **Exemplo inicial** pré-populado para demonstração

### 🎯 Sistema de Roast
- Analisa o código e gera críticas divertidas baseadas em:
  - Uso de `eval()` (vulnerabilidade de segurança)
  - SQL sem parâmetros (SQL injection)
  - TODOs no código (problemas pendentes)
  - Código muito curto ou sem comentários
  - E muito mais...

### 🏆 Leaderboard
- Exibe o ranking dos piores códigos analisados
- Mostra exemplos reais de código problemático
- Sistema de pontuação baseado na gravidade dos problemas

### 🎨 Design
- Interface moderna inspirada no design do Pencil
- Tema escuro com cores vibrantes
- Layout responsivo e intuitivo

## 🚀 Como Usar

1. **Acesse o aplicativo** na URL do deploy
2. **Cole ou edite** o código no editor
3. **Clique no botão** "roast_my_code"
4. **Leia a crítica** gerada e divirta-se!

## 🛠️ Tecnologias

- **Next.js 16** - Framework React
- **TypeScript** - Tipagem estática
- **Tailwind CSS v4** - Estilização
- **Compound Components** - Pattern de composição

## 🎓 Sobre o Projeto

Este projeto foi desenvolvido durante o **NLW (Next Level Week)** da **Rocketseat**, seguindo as aulas e lições do evento. O objetivo era criar uma aplicação web completa com foco em:

- **Experiência do usuário** - Interface intuitiva e divertida
- **Qualidade de código** - Boas práticas e padrões de projeto
- **Design system** - Componentes reutilizáveis com padrão de composição
